### Capacitor Notes
- Capacitor wraps the existing Next.js web app — **no separate codebase**
- Build output: `frontend/android/` directory (generated by Capacitor, not committed to git)
- Requires: Android Studio, Java 17+, Android SDK
- Target Android API: 24+ (Android 7.0)
- `capacitor.config.ts` in `frontend/` — points to Next.js build output
- OCR flow: `@capacitor/camera` → image → `Tesseract.js` → text → import modal
- Push flow: FCM token registered on app launch → sent to backend → backend triggers via FCM API
- Platform detection: `Capacitor.isNativePlatform()` used to show/hide camera import button

### Capacitor Dev Requirements (Phase 2 only)
- Android Studio (latest stable)
- Java 17 JDK
- Android SDK Platform 34
- `npx cap sync` after every frontend build

## External APIs

| Service | URL | Auth | Purpose |
|---------|-----|------|---------|
| Wiktionary REST API | `https://en.wiktionary.org/api/rest_v1/page/definition/{word}` | None | Word definitions — all languages, one endpoint |
| Firebase Cloud Messaging | `https://fcm.googleapis.com/v1/projects/{id}/messages:send` | Service account key | Push notifications (Phase 2) |

### API Caching Strategy
- Wiktionary responses cached in `word_definitions` table
- Cache key: `(word, language_code)` composite
- Cache TTL: indefinite
- Lookup: check cache → miss → call Wiktionary → cache on success

## Deployment

| Layer | Platform | Phase |
|-------|----------|-------|
| Frontend | Vercel | Phase 1 |
| Backend | Railway | Phase 1 |
| Database | Railway PostgreSQL | Phase 1 |
| Android App | Manual APK / Google Play | Phase 2 |

### Vercel Config (`vercel.json`)
```json
{
  "buildCommand": "cd frontend && npm run build",
  "outputDirectory": "frontend/.next",
  "installCommand": "cd frontend && npm install",
  "framework": "nextjs",
  "env": {
    "NEXT_PUBLIC_API_URL": "https://polyglot-backend.up.railway.app"
  }
}
```

### Railway Setup
- Service 1: FastAPI (`uvicorn main:app --host 0.0.0.0 --port $PORT`)
- Service 2: PostgreSQL (Railway managed, connection string auto-injected)
- Environment variable `DATABASE_URL` injected by Railway automatically

### Environment Variables

**Frontend** (`.env.local` for dev, Vercel env for prod):
```
NEXT_PUBLIC_API_URL=http://localhost:8000          # dev
NEXT_PUBLIC_API_URL=https://your-app.railway.app  # prod (set in Vercel dashboard)
```

**Backend** (`.env`):
```
DATABASE_URL=postgresql+asyncpg://user:pass@localhost:5432/polyglot  # dev
DATABASE_URL=<injected by Railway>                                     # prod
CORS_ORIGINS=http://localhost:3000,https://your-app.vercel.app
FIREBASE_CREDENTIALS_PATH=./firebase-service-account.json            # Phase 2
```

**Capacitor** (`frontend/capacitor.config.ts`) — Phase 2:
```typescript
const config: CapacitorConfig = {
  appId: 'com.carlos.polyglot',
  appName: 'Polyglot',
  webDir: 'out',           // Next.js static export for Capacitor
  server: {
    androidScheme: 'https'
  }
}
```
